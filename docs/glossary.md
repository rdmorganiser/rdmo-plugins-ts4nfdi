TS4NFDI Glossary:
* Term (=Class/Individual)
  * A term is a word, compound word, or multi-word expression that in specific contexts is given specific meanings—these may deviate from the meanings the same words have in other contexts and in everyday language. (source: Terminology - Wikipedia)
* Property
  * used to indicate attributes and relationships of some Thing (e.g. Term or Property). (source: https://schema.org/Property)
* Terminology=Ontology=Vocabulary
  * Terminology is a group of specialized words and respective meanings in a particular field, and also the study of such terms and their use (source: Terminology - Wikipedia)
* Terminology Collection
  * Is a set of terminologies.
* Entity Set
  * Is a set of terms and/or properties (from different terminologies).
* IRI/URI/URL
  * URL < URI < IRI
  * Uniform Resource Locator (URL)
    * A uniform resource locator (URL), colloquially known as an address on the Web[...] (source: URL - Wikipedia)
    * e.g. https://nfdi.de
  * Uniform Resource Identifier (URI)
    * A Uniform Resource Identifier (URI), formerly Universal Resource Identifier, is a unique sequence of characters that identifies an abstract or physical resource, such as resources on a webpage, mail address, phone number [...] (source: Uniform Resource Identifier - Wikipedia)
    * e.g. https://nfdi.de + mailto:ts4nfdi@lists.nfdi.de
  * Internationalized Resource Identifier (IRI)
    * The Internationalized Resource Identifier (IRI) is an internet protocol standard which builds on the Uniform Resource Identifier (URI) protocol by greatly expanding the set of permitted characters. (source: Internationalized Resource Identifier - Wikipedia)
    * e.g. https://nfdi.de + mailto:ts4nfdi@lists.nfdi.de + https://universität-berlin.de
